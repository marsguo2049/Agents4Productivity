# 🧠 子期 - AI驱动的个人成长绩效教练

子期是一个智能的个人生产力追踪和分析系统，通过对话解析、数据收集和多维度分析，帮助你了解自己的工作模式、优化时间管理，并发现提升效率的机会。它不仅是工具，更是陪伴你成长的智慧伙伴。

## 🤖 智能Agent团队

### 1. 心语 (心语 Agent)

**职责：**
- 倾听用户的内心话语，解析对话内容
- 智能区分"期望任务"vs"实际完成"
- 识别情绪状态和能量水平
- 按时间戳整理并存储数据

**工作流程：**
1. 接收对话输入
2. 分析内容类型（计划/执行/情绪）
3. 提取关键信息（任务、时间、情绪）
4. 存储到对应文件夹的当日文件中

**输出示例：**
```
expect/2024-11-12.md
## 09:00
- 完成项目报告的第一部分
- 回复所有重要邮件
- 准备明天的会议材料

actual/2024-11-12.md
## 10:30
- 完成项目报告第一部分 ✅
- 回复了5封重要邮件 ✅
- 会议材料准备未开始 ⏸️

emotion/2024-11-12.md
## 09:00 - 状态：专注，信心十足，开始一天工作
## 14:30 - 状态：疲劳，有些焦虑，连续工作3小时后
## 17:00 - 状态：满足，有成就感，完成主要任务
```

### 2. 蓝图 (蓝图 Agent)

**职责：**
- 分析`mission/`中的非结构化想法和目标
- 结合`expect/`中的具体期望任务
- 运用重要紧急四象限进行优先级排序
- 生成结构化的日计划、周计划
- 提供时间安排建议和资源分配方案

**工作流程：**
1. 收集并分析`mission/`中的原始想法
2. 整合`expect/`中的具体期望
3. 评估任务的重要性和紧急性
4. 考虑历史完成数据（来自`actual/`）
5. 生成最优的时间安排和优先级建议

**输出示例：**
```
plan/2024-11-12_plan.md
# 今日计划 (2024-11-12)

## 🔥 重要且紧急
1. 完成项目报告第一部分 (预计2小时)
2. 回复客户重要邮件 (预计30分钟)

## 📈 重要不紧急
3. 学习新技术文档 (预计1小时)
4. 制定下周计划 (预计45分钟)

## ⚡ 紧急不重要
5. 参加团队例会 (预计1小时)

## 📝 时间安排建议
- 09:00-11:00: 专注完成项目报告
- 11:00-11:30: 处理重要邮件
- 14:00-15:00: 参加例会
- 15:00-16:00: 学习时间
- 16:00-16:45: 计划制定
```

### 3. 回音 (回音 Agent)

**职责：**
- 根据指定时间段生成分析报告
- 整合多维度数据（期望vs实际、番茄钟、情绪）
- 计算关键指标和趋势
- 提供个性化洞察和建议

**分析维度：**
- **完成率分析**：计划vs实际差距
- **时间管理效率**：番茄钟利用情况
- **情绪生产力关联**：情绪对工作效果的影响
- **模式识别**：最佳工作时段、任务类型偏好

**报告结构：**
```
# 2024年11月12日 日报

## 📊 核心指标
- 计划任务完成率：75%
- 专注时间：4.5小时
- 平均专注时长：45分钟
- 情绪状态：总体积极

## 🎯 计划vs实际
- ✅ 已完成：3项主要任务
- ⏸️ 进行中：2项任务
- ❌ 未开始：1项任务

## 💡 洞察与建议
- 上午9-11点是你的最高效时段
- 建议将复杂任务安排在情绪积极时
- 需要注意午后精力管理

## 📈 趋势分析
- 本周完成率趋势：上升 ↗️
- 情绪稳定性：良好
- 时间利用效率：有提升空间
```

### 4. 灵犀 (灵犀 Agent)

**职责：**
- 长期趋势分析和深度模式识别
- 个人生产力习惯挖掘与认知偏差洞察
- 技术突破过程分析
- 预测性分析

**核心分析能力：**
- **自我认知偏差分析**：识别计划过于乐观/保守的模式
- **生物钟优化**：发现个人最佳工作时间段
- **任务类型匹配**：分析不同任务类型的完成效率
- **情绪管理策略**：识别影响生产力的情绪因素
- **技术问题解决模式**：分析复杂技术问题的解决路径和突破口

**报告存储：** 所有分析报告保存在 `reports/analysis/` 目录下

## 🚀 使用流程

### 日常使用
1. **想法收集** → 随时记录想到的事情到`mission/`
2. **开始工作前** → 让蓝图Agent基于mission生成今日计划
3. **工作中** → 随时更新进度和状态
4. **遇到情绪波动** → 记录当前感受
5. **结束工作** → 导入番茄钟数据
6. **每日回顾** → 自动生成日报

### 数据输入方式
- **Mission记录**：非结构化的想法、目标、灵感
- **对话式输入**：自然语言描述计划和进展
- **番茄钟导入**：从番茄钟应用导出数据
- **情绪记录**：简单描述当前状态

### 报告获取
- **日报**：每日21:00自动生成
- **周报**：每周日21:00自动生成
- **月报**：每月最后一天21:00生成
- **自定义报告**：随时请求特定时间段分析

## ✨ 系统特色

- **🎯 个性化分析**：完全基于你的个人数据
- **📉 模式识别**：发现你的独特工作节奏
- **💡 智能建议**：基于数据驱动的改进方案
- **🔄 持续优化**：随着数据积累越来越准确
- **🧠 情绪感知**：关注心理状态对生产力的影响
- **🤝 温暖陪伴**：如知音般理解你的成长伙伴

## 🎮 快速开始

1. **创建今日文件**：在各个data文件夹中创建今日的.md文件
2. **记录想法**：把所有想做的事情都记到`mission/`中
3. **生成计划**：让蓝图Agent为你创建结构化计划
4. **开始对话**：按照计划执行，随时更新进度
5. **保持更新**：记录进展和情绪状态
6. **导入数据**：结束时导入番茄钟记录
7. **查看报告**：让系统为你生成今日分析
