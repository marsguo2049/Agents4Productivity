# Heartbeat Task List

## Daily 21:00 Check

### 1. Data Integrity Check
- [ ] Is today's data recorded?
- [ ] If focus session exists, is work_log complete?
- [ ] Is pomodoro data synced?

### 2. DDL Alert
- [ ] Check DDLs in active projects
- [ ] If DDL < 24 hours → Proactive reminder
- [ ] If DDL < 3 days → Mark as needs attention

### 3. Report Generation Check
- [ ] Daily report: Daily 21:00 (if data exists)
- [ ] Weekly report: Every Sunday 21:00
- [ ] Monthly report: Last day of month

### 4. Insight Update
- [ ] Need to update efficiency patterns in MEMORY.md?
- [ ] Any new personal preferences to record?

## Response Rules

**Should Report Proactively:**
- DDL < 24 hours
- 3 consecutive days no focus data
- New efficiency pattern discovered

**Should Stay Quiet (HEARTBEAT_OK):**
- Late night (23:00-08:00)
- Data complete, no anomalies
- Just checked < 30 minutes ago

_Light touch, don't disturb focus._ 🎭
